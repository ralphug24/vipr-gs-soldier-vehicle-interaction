# My Unity 3D environment

## What I built

I built an environment with terrain and added sound and visual effects to represent environmental impediments, including noise, cloudy conditions and rain.

## Implementation decision

I represented operating conditions through terrain, audio and weather effects so NUI interactions could be explored under different environmental conditions.

## Intended evaluation

The environment was intended to help test how people react to natural user interfaces when conditions change.

## Scope

This page documents my simulation and prototyping work. The empirical method reported in the linked journal paper is interview research. The repository provides an implementation overview, rather than a runnable Unity project or a new performance dataset.
